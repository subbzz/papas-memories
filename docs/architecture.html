Papa's Memories Architecture

A static scrapbook site on Cloudflare Pages. Media stays in a private SharePoint site and is only ever streamed through a server-side proxy. Two sign-in paths meet at one gate: Microsoft Entra ID for Dada and Mama, and a Cloudflare Access email PIN plus Dada's approval for family.

Components and trust boundaries

Browsers never hold a SharePoint address. Every clip travels through /api/stream, which re-checks a signed six-hour link on each request before fetching from Graph with an app identity that can read only this one site.

Request flows

The desktop flow is Dada or Mama on the main site. The mobile flow is a family member on an iPhone: the media player fetches without cookies, which is why playback uses a signed link instead of the Access session.

Controls at each boundary

Each layer checks independently, so a request that slips past one still meets the next.
